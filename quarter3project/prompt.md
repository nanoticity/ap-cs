Objectives:
The objective of this project is to use concepts we have learned so far to create a card game. Concepts that will be used include loops, logic, class creation, object instantiation, constructor and method implementation, parameter passing, return values, code organization, encapsulation, ArrayList of Objects, scrambling, and adherence to coding conventions (comments, naming conventions, etc.). Follow all directions carefully!

Project Description: For the Quarter 3 Project, you will create a pre-approved card game of your choice. Your game must be unique from others. Your game must demonstrate all of the required features and rubric criteria. You can work individually on your project or work with only one partner.
Individual - The card game is a 2-player game.
Group of 2 -The card game must be a 3-4 player game. 2 or more of the players are humans. One of the players must be an AI player.

Required Features
Your game must be School-appropriate.
Your game must be written in Java.
The game is graphical.
A start screen that explains the game with instructions and allows the user to begin playing.
You must graphically display which player's turn.
An end screen to end the game and report any game statistics to the user (who wins, score, etc.).
Use only ArrayList for your cards.
Players take turns. You will pass the computer around between the players' turns. The screen will be blank when transferring to another player, so you don't see each other's cards if the game requires it. The next player will press a button to disable the blank screen.
Shuffling of Cards for each new game.
The game logic for your functioning card game is contained in a modular CardGame class.
At least 2 different sounds given 2 different actions. Here is an example code of sound. Implementing Sound (Wav files only) - Link Wav files can be found at https://freesound.org/ or wavsource
Player interactions via buttons and/or mouse clicks.
There is a cheat key of "p" to progress from the start screen to the game screen to the end screen.

Required Classes: You must implement the following classes.

Card Class
This class contains the information on the game card.

CardGame Class
This class has the game mechanics, the ArrayList of Cards, and the graphics of your game.

Table Class
This is your JPanel.  
This is where the CardGame class is instantiated and used.
This is where user interactions are handled such as buttons and/or mouse inputs.

Runner Class
This class runs the game putting together the JPanel and JFrame.

You can implement additional classes if needed.
